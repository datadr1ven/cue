What we alert on

GridWhisper turns live F1 timing into the moments that matter — not every purple sector. Prefer silence over noise. Live timing can lag; this is unofficial.

Practice (FP1–FP3)

You get

  • Session start / finish
  • Finish recap (fastest, compounds, busiest pitters)

You don’t

  • Position thrash, pits, radios
  • “Someone went P7→P4”

Qualifying

You get

  • Q1 / Q2 / Q3 start
  • A few session-bests in Q1/Q2 (capped)
  • Chequered + “into the cut” drama
  • Q1/Q2 cut summary when the next segment starts
  • Q3 provisional pole at the flag
  • Provisional top 3 again if P1–P3 change after the flag (flying laps)

You don’t

  • Every purple / race-style “big swings”
  • Session-best spam in Q3
  • Grid penalties / Sunday starting grid
  • A timer that “finalizes” Q3 — board-driven only

Race (and sprint race)

You get

  • Green / chequered / finish (incl. under SC when relevant)
  • Lead change into P1
  • Big swings only when someone jumps ~5+ places (filtered)
  • Pits; louder for top cars under safety car
  • SC / VSC / red
  • A few top‑3 team radios
  • Rain starting; notable steward notes

You don’t

  • Processional order every few seconds
  • Tiny place swaps
  • Every radio clip
  • Red-flag tyre-change pit spam

Why didn’t I get …?

Someone gained 2 places in Q3?
Place-swing alerts are for the race, and need a large jump. In quali we use provisional pole / top‑3 updates instead.
Final Q3 order after flying laps?
If P1–P3 change after the flag, we re-post the provisional top 3. We don’t run a settle timer.
Driver “P8” in the press but we said P3?
That’s usually a grid penalty for Sunday — not the same as qualifying order, and not always in the live timing feed.
Every purple in Q1?
Session-bests are capped and spaced so the feed stays readable.
